PRODUCT CASE STUDY

从机械背景，到 AI 产品实践。

一个围绕真实问题设计、以可验证结果为目标的个人项目起点。

01 / PROBLEM

查得到资料，却不容易找到答案

假设目标用户是刚接触设备的工程师：手册分散、同类报警在不同机型含义不同，查找结果也需要核对。

这是待验证的用户假设；本 Demo 未进行真实用户访谈或企业部署。

02 / SOLUTION

设备范围 → 资料检索 → 来源核对

先明确设备，再找相关资料。把来源放在答案旁边，并保留无法确认与用户反馈的路径。

当前范围：三类示例设备、文本资料导入、原文查询、反馈和固定用例自测。

03 / CURRENT SCOPE

现在可以演示什么

  • 关键词与有限同义词匹配，直接展示原文
  • 按设备隔离资料，识别部分型号冲突
  • 本地 TXT / Markdown 导入与检索
  • 按场景推荐、收藏问题、导出查询与测试结果；携带问题转入售后

尚无语义理解、生成式回答、PDF 解析、服务器数据库或多人共享。匹配到片段不等于问题已被完整回答。

04 / NEXT ITERATION

下一步，用证据推动迭代

  1. 访谈 3—5 位目标用户，确认最常见的查询任务。
  2. 整理有使用权限的真实手册与参考答案。
  3. 接入服务端模型与检索，保护密钥。
  4. 比较人工查阅与助手查询，记录失败案例。
